Week 1 - Dev Tools and HTML Basics

Goals:

  • Set up my computer for web development.
  • Move from terminal dev to a professional IDE.
  • Start a web site to track my dev journey.


This week I finally dipped my toe into website development. Most of my time was spent learning dev tools and HTML5 markup elements, the very basics.


After using Firefox and Safari pretty much my whole life, I'm opening my heart up to Chromium. MDN recommends a mix of browsers to make sure that your code works everywhere, so I'm giving into Google.



For a curriculum, I'm using The Odin Project. I'll follow the lesson plans to help create this dev log, and professionalize my online presence in general.



When I first started coding, I used Python's build-in IDLE editor, but quickly moved over to Vi and Vim. On the advice of many web dev's, I'll be using VS Code because of the integrated browser, but I still launch my pages in my browser from terminal, lol. For the foreseeable future, I'll try to keep learning VS Code so I can be a cool kid.



Though I've been using Git locally for a year now, but I'm not going to lie, GitHub intimidates me. Nevertheless, I'm biting the bullet and am going to host this blog on GitHub Pages for now. This week I set up an ssh and finally figured out how to push to an online repo from my terminal.
